填回覆 POST /entries

自己填，或主辦人幫大家填：存一筆就自動清空接著填下一位。要改誰的就在右下「所有回覆」按編輯。

一般轎車 5、休旅 7。國道高乘載管制要 3 人以上（含駕駛）。
對方還沒填也可以先指定，等他填出車就會自動配上。
把這串貼到群組，主辦人匯入就會出現在乘車板。
主辦人工具：匯入答案代碼

別人在自己手機上填完按「複製答案代碼」貼給你，整段貼進來，一次可貼多個，就會進你的乘車板。

乘車板 GET /cars

指定司機優先配，其餘依車的順序補位。深琥珀是駕駛，亮琥珀是乘客。要改回覆到下方「所有回覆」按編輯。

行程時間軸 GET /ideas

提案時選第幾天＋幾點就直接排進時間軸，沒選的留在候選區。點時間軸上的格子＝投一票，票越多顏色越亮；每一項的天數與時間下面都能改。
