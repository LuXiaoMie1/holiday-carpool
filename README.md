# 連假出遊乘車調度

14 人出遊的乘車登記頁：選出車／搭車、自動配車、高乘載檢查、行程提案投票。
不用登入，任何人開連結就能填。

- 頁面：`docs/index.html`，放在 GitHub Pages
- 後端：`apps-script/Code.gs`，綁在一張 Google 試算表上的 Apps Script 網頁應用程式
- 資料：試算表裡的 `store` 工作表（col / id / json / updatedAt），想看原始資料直接開試算表

## 用法 A：不接任何後端（最省事）

開 https://luxiaomie1.github.io/holiday-carpool/ ，主辦人自己把 14 個人一筆一筆填進去（存一筆會自動清空接著填下一位），資料存在自己瀏覽器裡。
填完按乘車板右上「複製分享連結」，貼到群組：大家開連結就看到目前的板（資料壓在網址裡）。
別人要加自己也可以：開連結 → 填 → 再按「複製分享連結」貼回群組，主辦人開了會自動合併（同一筆以較新的為準）。

## 用法 B：接 Google 試算表後端（大家各自填、即時同步）

### 一次性部署（主辦人做，約 5 分鐘）

1. 用你的 Google 帳號開一張新的試算表（sheets.new），隨便取名，例如「出遊乘車」。
2. 試算表上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡預設的 `function myFunction(){}` 全部刪掉，貼上 `apps-script/Code.gs` 的全部內容，Ctrl+S 存檔。
4. 右上 **部署 → 新增部署作業**：
   - 左邊齒輪選「網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**任何人**（不是「任何擁有 Google 帳戶的人」）
   - 按「部署」
5. 第一次會跳授權：選你的帳號 → 「進階」→「前往（專案名稱）(不安全)」→ 允許。這是 Google 對自己寫的腳本的標準警告。
6. 複製畫面上的「網頁應用程式 網址」（`https://script.google.com/macros/s/.../exec`）。
7. 把那串網址貼給 Claude（或自己把 `docs/index.html` 裡的 `__API_URL__` 換掉），push 上 GitHub，頁面就通了。

驗證：瀏覽器直接開那串 `/exec` 網址，應該看到 `{"entries":{},"ideas":{},"meta":{}}`。

## 之後要改後端程式

Apps Script 改完存檔後要 **部署 → 管理部署作業 → 鉛筆 → 版本選「新版本」→ 部署**，網址不變。只存檔不重新部署的話，線上跑的還是舊版。

## 注意

- 知道 `/exec` 網址的人都能寫資料，這是為了讓大家免登入；網址只貼在你們群組就好。
- 試算表是唯一的資料來源，刪列就等於刪資料。
